# LUNA ESTATE — золотая коллекция

Готовый статический сайт. Основная рабочая папка: C:\Users\jhn_l\repository\LUNA ESTATE.
Для размещения скопируйте **содержимое dist** в выбранную папку GitHub Pages, сохранив assets и скрытый .nojekyll. index.html должен лежать непосредственно в папке публикации. Сборка и установка зависимостей владельцем не требуются.

## Просмотр и упаковка

Локальный просмотр: http://127.0.0.1:4175/dist/index.html
Для запуска просмотра при установленном Node.js: `node serve.cjs`.
После правок исходников: `node package-site.cjs`. Скрипт только копирует публикационные файлы в dist.
Папки work, .git и проверочные скрипты публиковать не нужно. Резерв исходной версии — work/before-gold.

## Поведение

На широком экране участки выбираются справа; ниже 1024 px список открывается кнопкой «Участки · 6».
Выбор обновляет карту, панораму, сведения, образец сертификата и финальную кнопку оформления.
Панораму можно перемещать по горизонтали указателем или стрелками клавиатуры; доступны весь атлас и развёрнутый просмотр.
Escape закрывает верхнее открытое окно и возвращает фокус. Ошибка изображения сохраняет выбор и позволяет повторить загрузку.
Крупные изображения загружаются для выбранного и следующего участка; остальные — по запросу.
Имя хранится только в памяти текущей страницы. Хранилища, отправка имени, платежи и реальные заказы отсутствуют.
Без JavaScript остаются текст и список всех предложений. Уменьшение движения отключает пролёты и декоративное движение.
Фотографическая фоновая сцена, Земля и многослойная прокрутка сохранены. WebGL не используется.
