# LUNA ESTATE

Учебный лендинг: вымышленная продажа лунных участков как идея для домашнего задания. Шесть художественных панорам, выбор участка и именной сувенирный сертификат. Платежей, отправки имени и передачи права собственности нет.

Опубликованная страница: https://jhnleon11.github.io/LUNA-ESTATE/
Репозиторий: https://github.com/jhnleon11/LUNA-ESTATE
Основная папка: C:\Users\jhn_l\repository\LUNA ESTATE.

## Просмотр и сборка

Нужен Node.js 18 или новее. Зависимостей для установки нет.

- Локальный запуск: `npm start` или `node serve.cjs`.
- Просмотр исходников: http://127.0.0.1:4175/index.html
- Сборка статической копии: `npm run build` или `node package-site.cjs`.
- Просмотр сборки: http://127.0.0.1:4175/dist/index.html
- Автоматические проверки: `npm test` или `node --test tests/site.test.cjs`.

GitHub Pages публикует корень ветки main. Папка dist является локальной копией для проверки и передачи; она не добавляется в Git. При переносе на другой хост нужно обновить канонический адрес, Open Graph, JSON-LD и sitemap.xml.

## Три дизайна одной страницы

Кнопки в первом экране переключают «Золото», «Орбита» и «Лунный свет». Содержание, цены, площади и исходные изображения общие. Варианты отличаются палитрой, типографикой, формой кнопок и панелей.

Выбор сохраняется локально. При недоступном хранилище переключение работает до перезагрузки. Прямая ссылка может содержать `?design=gold`, `?design=orbit` или `?design=moonlight`; параметр имеет приоритет над сохранённым выбором. Кнопка «Назад» восстанавливает дизайн. Все варианты имеют один канонический URL и не создают отдельных сайтов.

При переключении дизайна выбранный участок, изображение, положение обзора и введённое имя сохраняются. Для смены дизайна сначала закройте открытый диалог: его фон недоступен, как и положено модальному окну.

Обзор панорамы: перетаскивание или стрелки. На узком экране список открывает кнопка «Участки · 6». Кнопка «Развернуть» открывает кинозал. Ночь/рассвет изменяет освещение текущей панорамы. При ошибке изображения можно повторить загрузку. Предзагрузка следующего участка отключается, когда браузер сообщает saveData.

Имя остаётся в памяти страницы и исчезает после перезагрузки. Сертификат можно распечатать или сохранить через меню печати браузера. Уменьшение движения учитывается существующими CSS и JS. Без JavaScript остаются тексты, галерея и список предложений.

## Файлы и происхождение графики

- index.html — содержание и SEO-метаданные; sitemap.xml — один канонический адрес.
- styles.css, journey.css, refinements.css, gold.css — исходное оформление.
- designs.css, designs.js — варианты дизайна и переключение.
- script.js, panoramas.js — выбор, диалоги, панорамы и сертификат.
- assets — все локальные изображения; assets/panoramas — шесть панорам в трёх размерах.
- docs/AUDIT_2026-10-11.md — анализ изменений и ограничения.
- docs/qa — результаты проверки и контрольные снимки текущей доработки.
- tests/site.test.cjs — проверки комплектности, SEO и поведения переключателя.
