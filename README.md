# LUNA ESTATE

Готовый статический лендинг для самостоятельного размещения на GitHub Pages.

## Что скопировать

Скопируйте всё содержимое этой папки в выбранную папку публикации репозитория, сохранив структуру assets. index.html должен находиться непосредственно в папке публикации. Включите скрытый файл .nojekyll. Не копируйте рабочие проверки, резервные версии и папку work из основного проекта.

Сборка, серверные интерфейсы и установка зависимостей не требуются. Пути относительные: сайт работает как в корне домена, так и в подпапке репозитория. README.md можно сохранить в репозитории.

## Содержание

Шесть вымышленных лунных участков, карта с приближением и переключением освещения, персональный сувенирный сертификат и печать на A4. Имя остаётся в текущей странице; сайт не отправляет его на сервер и не сохраняет в браузере. Платежей и реальных заказов нет.

Текст лендинга и список участков доступны без JavaScript. При уменьшении движения анимации отключаются. Шрифты загружаются через Google Fonts; при недоступности сети используются Georgia и Arial. Остальные ресурсы сайта находятся в этой папке.

Земля, лунная поверхность и карта созданы с помощью ImageGen. Это художественные изображения. Участки, названия и цены вымышлены; сертификат не подтверждает право собственности.

## Проверка

Проверены размеры 360, 390, 760, 1024, 1440 px и окно 1920 × 720, карта, клавиатура, имена до 60 символов, уменьшение движения, режим без JavaScript и одностраничная печать A4 без фоновых заливок. Проверка выполнена в настольном Chrome с эмуляцией размеров. Реальные телефоны и физический принтер не проверены. Публикация выполняется владельцем самостоятельно.
