# Панорамы LUNA ESTATE

Все шесть изображений — художественные произведения ImageGen, а не фотографии реальных участков или точная реконструкция рельефа. Названия основаны на реальных лунных местах. Площадь относится к сувенирному предложению, а не ко всему названному объекту.

01 — База Спокойствия / Statio Tranquillitatis, Море Спокойствия. VIP. Далёкая посадочная ступень Eagle служит исторической отсылкой; аппарат не является предметом продажи. Верхней ступени в композиции нет.
02 — Кратер Аристарх / Aristarchus.
03 — Мыс Гераклида / Promontorium Heraclides.
04 — Альпийская долина / Vallis Alpes.
05 — Океан Бурь / Oceanus Procellarum.
06 — Море Ясности / Mare Serenitatis. Положение Земли в художественном изображении не является астрономическим расчётом.

Изображения 02–06 сохранены из предыдущего художественного набора. Новая панорама 01 создана и затем исправлена по пожеланию владельца: главный предмет изображения — простор лунного грунта, модуль находится далеко у горизонта.
