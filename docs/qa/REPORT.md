# Проверка учебного задания — 11 октября 2026

Проверена текущая рабочая версия после добавления трёх дизайнов. Среда: Windows, Node.js 24.19, встроенный браузер Codex. Скриншоты в этой папке относятся к этой проверке, а не к прежним архитектурным экспериментам.

## Подтверждено

- `npm test`: четыре проверки проходят. Проверяются SEO-разметка, локальные ресурсы, выбор дизайна, история и работа без доступного localStorage.
- `npm run build`: локальная dist собрана. `git diff --check` и проверка синтаксиса JavaScript проходят.
- Все три дизайна на ширинах 360, 390, 760, 780, 1024 и 1440 px: горизонтального переполнения нет; семь внешних панелей имеют одинаковую ширину. Повторная проверка после последних правок записана в `responsive-checks.json`.
- В шапке на узком экране скрываются навигация и дополнительная ссылка; на широком экране элементы не пересекаются.
- Подпись панорамы — 12 px; кнопки выбора дизайна имеют минимальную высоту 44 CSS px (дробные значения в измерении связаны с округлением браузера).
- Открыты все шесть участков. Смена дизайна сохранила участок № 03, изображение и положение обзора 57% center.
- Имя «Александра» сохранилось после смены дизайна и повторного открытия формы. Создан сертификат для участка № 03; бумажное оформление сохранено.
- Открыт кинозал с выбранной панорамой и освещением «Рассвет». Escape закрывает его и возвращает фокус кнопке открытия.
- На ширине 390 px список участков открывается; выбор клавишей Enter закрывает список и возвращает фокус.
- Прямая ссылка `?design=orbit`, переключение клавишей Enter, сохранение якоря, переход назад/вперёд и перезагрузка проверены в браузере.
- Исходные растровые ресурсы не изменены. Для галереи используются существующие миниатюры; исходник большого фона сохранён, страница использует вариант 2880 px.

## Ограничения

Проверка размеров выполнена в браузере, не на физических телефонах. Реальные сенсорные жесты, системное предпочтение уменьшенного движения, режим экономии трафика и искусственные сетевые ошибки отдельно не эмулировались; соответствующие существующие обработчики сохранены, условие saveData проверено по коду. Печатный PDF и физическая печать не проверялись: подтверждён экранный сертификат. Не измерялись Lighthouse, Core Web Vitals, позиции поиска или объём первой загрузки. Разметка карточек соцсетей проверена статически; реальные карточки и индексация Google не подтверждены. Публикация и архив проверяются отдельно после фиксации изменений. Сдача через учебную платформу остаётся пользователю: доступ к ней не предоставлен.
